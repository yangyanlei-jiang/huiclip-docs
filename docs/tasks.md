# 派任务与验收

1. 打开组织的任务页，新建任务。用一句话描述要交付什么，例如「在试用项目中检查 README 的启动步骤」。在正文写清输入、允许操作范围与验收条件。
2. 将任务分配给已配置的 Agent，确认任务的项目和工作目录。任务可先保留给自己检查，再转交给 Agent。保存后记下任务编号。
3. 从任务对话或 Agent 详情检查运行。看看运行状态、回复和工作产物。出现审批时，先阅读类型、范围和影响，再由有权限的人作决定。
4. 验收时逐项核对交付物和运行结果。对文件变更查看差异，并按原任务约定运行检查。需要补做时在同一任务补充一条具体要求。完成后再把状态改为完成。

一个合适的首单任务可以这样写：

> 只读取试用仓库根目录的 README。列出启动命令、默认端口和两种你认为需要用户确认的前置条件。附上文件位置。保持工作目录内容原样。

从费用或预算页面核对组织和 Agent 的花费、使用量与额度。预算是工作范围的一部分。第一次试跑可先设小额度，再决定是否扩大任务。
