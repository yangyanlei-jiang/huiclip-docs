# 常见排障

## 启动或打开页面失败

- 先核对 `node --version` 和 `pnpm --version`。依赖安装使用仓库锁文件。若依赖解析指向团队 registry，先用组织允许的方式确认该 registry 能获取公共依赖。
- 用 `huiclip info` 确认配置文件和端口。用 `curl -fsS http://127.0.0.1:1549/api/health` 区分服务启动和浏览器问题。
- 依赖构建失败后可重试 `huiclip setup`。如果机器在构建时突然断电，先确认没有仍在运行的构建，再检查该版本专属的运行目录和锁目录。保留 `instances/` 和重要日志。
- 迁移失败时保留原数据目录与首条错误，在新测试目录复现。

## 页面语言和预期不同

- 在个人设置里确认语言。浏览器会记住主动选择。新浏览器会话可用于检查首次访问时的默认语言。
- 报告残留英文时请附当前提交、页面、触发操作和实际界面词。用户输入、模型名和运行日志按原样显示。

## 连接模型时提示 paperclip_runner_binary_missing

HuiClip 0.1.3 缺少运行订阅连接检查所需的原生程序。保留已有的 `HUICLIP_HOME`，关闭旧进程，用按[安装指南](./install.md)生成的 0.1.4 本地包装到原前缀，重新启动后在原页面重试。这个错误出现在本机运行器发现阶段，无需为此重置模型账号或更换 API 密钥。首次准备会从公共 npm 下载固定版本的上游服务器包，校验后安装当前系统对应的运行器。

## Agent 未运行或运行失败

- 先检查任务是否已分配、Agent 是否处于暂停状态、是否等待审批，以及预算是否达到上限。
- 检查执行端账号、路径与 Codex 登录状态。复制给维护者之前先脱敏，保留错误类型、时间和任务编号即可。

反馈模板和验证记录可在社区分支根目录的 `README.zh-CN.md` 找到。
