# Paperclip 中文文档

这套中文指南以 HuiClip（Paperclip 中文社区版）为例，方便你从本机试用走到团队协作。若使用 Paperclip 上游版，安装命令和部分界面会有差异，请以 [上游项目](https://github.com/paperclipai/paperclip)为准。

## 第一次搭建

1. [安装并启动](./install.md)：核对 Node.js 环境，启动实例并创建试用团队。
2. [接入 Codex](./codex.md)：确认本地 Codex 可用，核对适配器、工作目录与权限。
3. [派任务与验收](./tasks.md)：用一个小任务跑通分派、执行与检查结果。
