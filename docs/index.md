# Paperclip 中文社区版：HuiClip

HuiClip 是基于开源 [Paperclip](https://github.com/paperclipai/paperclip) 的中文社区版，面向希望用中文管理 AI 团队的开发者。你可以在这里了解如何接入 Codex、分派任务、处理审批和查看预算。

HuiClip 由社区独立维护，不是 Paperclip 官方中文版。应用源码基于采用 MIT 许可证的上游版本，安装使用独立的 npm 包 `huiclip`。

## 安装并启动

```sh
npx --yes huiclip@latest run
```

[查看安装要求和升级步骤](./install.md) · [浏览 HuiClip 源码](https://github.com/yangyanlei-jiang/huiclip)

## 开始使用

第一次用 Paperclip，可以先读 [Paperclip 中文文档](./handbook.md)。如果你已经在用上游版，先看[团队私有部署](./private.md)和[实例存储目录](./local-storage.md)，分清现有实例和新的试用环境。
