# 检查费用与预算

在组织设置中进入费用，选择需要查看的日期范围。费用页显示已记录的费用和用量。打开「预算」页，可以查看组织、Agent、项目的额度与当前预算事件。

试验时先给一名 Agent 设置额度，记录修改前后的值。出现预算审批时，先核对申请人、当前用量和建议的新额度，再决定批准或拒绝。预算达到停止阈值时，检查 Agent 或项目为何暂停，然后决定维持暂停或调整额度。订阅账号的周期额度单独在服务商页显示。

下图来自本地验收组织，展示预算管理页面。向下滚动到 Agent 预算，可以核对本次设置的 15 美元额度。

![HuiClip 预算页的本地测试额度](/img/huiclip-budget.jpg)

对账时记录币种、日期范围和数据来源。额度、用量和账单是不同字段，比较时先确认口径。

参考 [Paperclip 费用页](https://docs.paperclip.ing/guides/day-to-day/costs/)。
