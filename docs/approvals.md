# 处理审批和决策

从收件箱或审批列表进入请求，先看关联任务和请求来源。审批通过前，对照已授权的工作范围、涉及的环境和可能的费用。通过、拒绝或要求修改时留下理由，便于回到任务继续核对。

在本地验收中，打开待审的演示请求并点击「批准」，详情页显示「审批已确认」。

以预算例外为例，先在[费用与预算](./budgets.md)里确认受影响的 Agent 或项目。用无外部副作用的小任务复核恢复后的状态，并保留审批历史。创建测试审批的方法取决于组织已开启的策略，真实的付费或外部权限变更应使用团队自己的审批流程。

参考 [上游审批](https://docs.paperclip.ing/guides/day-to-day/approvals/)和 [决策](https://docs.paperclip.ing/guides/day-to-day/decisions/)。
